# Testing Checklist

このドキュメントは、WanderingSea の変更後に確認すべき手動テスト項目を整理する。

関連ドキュメント:

- `docs/frontend-flow.md`
- `docs/data-model.md`
- `docs/gas-api.md`
- `docs/deployment.md`

## 基本方針

- フロントエンド変更時も GAS API への影響を確認する。
- GAS 変更時もフロントエンドの request/response 処理を確認する。
- API 契約が変わる場合は `docs/gas-api.md` を更新する。
- `gas/appsscript.json` は明示依頼なしに変更しない。

## 静的確認

| 項目 | 確認内容 |
|---|---|
| HTML | `index.html` の script/css パスが正しい。 |
| JS | ブラウザコンソールに構文エラーがない。 |
| CSS | 主要 UI が崩れていない。 |
| JSON | `lang/language.json` が正しい JSON。 |
| Link | `link/*.txt` が `表示名,URL` 形式。 |
| GAS | `gas/IDSearchSystem.js` の request/response が `docs/gas-api.md` と一致する。 |

## 初期表示

- ページが読み込める。
- タイトルが表示される。
- 説明文が表示される。
- 最新掲載状況欄が表示される。
- 検索フォームが表示される。
- 言語切替ボタンが表示される。
- フッターリンクが表示される。
- コピーライトが表示される。

## 言語切替

日本語:

- `JP` を押すと日本語文言になる。
- 入力欄 placeholder が日本語になる。
- フッターリンクが日本語になる。
- `localStorage.lang` が `ja` になる。

英語:

- `EN` を押すと英語文言になる。
- 入力欄 placeholder が英語になる。
- フッターリンクが英語になる。
- `localStorage.lang` が `en` になる。

共通:

- 切替後に検索しても結果カードのラベルが選択言語になる。
- ページ再読み込み後も選択言語が維持される。

## 検索入力

| ケース | 期待結果 |
|---|---|
| `name` と `title` が空 | API を呼ばず、入力エラーを表示。 |
| `name` のみ | `name` パラメータ付きで検索。 |
| `title` のみ | `title` パラメータ付きで検索。 |
| `name` と `title` | AND 条件で検索。 |
| 前後に空白 | trim された値で検索。 |
| Enter キー | 検索が実行される。 |
| 検索ボタン | 検索が実行される。 |

## 検索結果

| ケース | 期待結果 |
|---|---|
| 1 件ヒット | 1 枚の結果カードが表示される。 |
| 複数件ヒット | 複数の結果カードが表示される。 |
| 該当なし | GAS のエラーメッセージが表示される。 |
| 30 件超 | 絞り込みを促すエラーが表示される。 |
| 通信失敗 | `error_connection` が表示される。 |
| 連続検索 | 古いリクエスト結果で画面が上書きされない。 |

結果カード:

- ID が表示される。
- 投函日が表示される。
- 差出人が表示される。
- タイトルが表示される。
- HTML 特殊文字が実行されず、文字として表示される。

## ID コピー

- コピーアイコンを押すと ID がクリップボードに入る。
- コピー成功時にアイコンが `check` に変わる。
- 約 1.5 秒後に元のアイコンへ戻る。
- HTTPS または clipboard が許可された環境で確認する。

## 最新掲載状況

- `LAST_UPDATE_API_URL?callback=callback` が呼ばれる。
- JSONP が `callback(...)` を返す。
- `data.last_updated` が `#last-update-time` に表示される。
- API 失敗時に画面全体が壊れない。

## 外部リンク

- 手紙投函フォームが新規タブで開く。
- X DM リンクが新規タブで開く。
- ID 検索方法の YouTube リンクが新規タブで開く。
- `rel="noopener noreferrer"` が付与される。

## GAS API

検索 API:

- `GET ?name=...` が成功する。
- `GET ?title=...` が成功する。
- `GET ?name=...&title=...` が成功する。
- 両方空の場合 `status: "error"` を返す。
- 該当なしの場合 `status: "error"` を返す。
- 30 件超の場合 `status: "error"` を返す。
- 成功時 `status: "success"` と `data[]` を返す。

データ:

- `data[].id` が存在する。
- `data[].date` が `yyyy/MM/dd` 形式。
- `data[].name` が存在する。
- `data[].title` が存在する。
- ID 空行が返らない。

## レスポンシブ表示

- モバイル幅で入力欄とボタンがはみ出さない。
- 結果カードの ID がはみ出さない。
- 英語文言が表示領域を壊さない。
- フッターリンクが見切れない。

## リリース前の最小確認

1. 初期表示。
2. JP / EN 切替。
3. 空検索エラー。
4. 差出人名検索。
5. タイトル検索。
6. 結果カード表示。
7. ID コピー。
8. 最新掲載状況表示。
9. フッターリンク。
10. ブラウザコンソールエラーなし。

## 既知の注意点

- `debug_error` は専用表示がない。
- `No results found.` は翻訳されない。
- 最新掲載状況 API の実装はこのリポジトリ内で確認できない。
- GAS キャッシュにより、データ更新直後は検索結果が古い可能性がある。
