# Internationalization

このドキュメントは、WanderingSea の日本語・英語表示、翻訳キー、言語別リンクの管理方法を整理する。

関連ドキュメント:

- `docs/frontend-flow.md`
- `docs/testing-checklist.md`

## 対象ファイル

| ファイル | 役割 |
|---|---|
| `lang/language.json` | UI 文言、説明文、エラー文、ラベルを定義する。 |
| `js/i18n.js` | 翻訳 JSON の読み込みと DOM 反映を行う。 |
| `link/link_ja.txt` | 日本語表示時のフッターリンク。 |
| `link/link_en.txt` | 英語表示時のフッターリンク。 |
| `index.html` | 翻訳対象 DOM に `data-i18n` / `data-i18n-placeholder` を付与する。 |

## 対応言語

| 言語コード | 表示名 | 備考 |
|---|---|---|
| `ja` | JP | デフォルト言語。 |
| `en` | EN | 英語表示。 |

初期言語:

```js
localStorage.getItem('lang') || 'ja'
```

## 翻訳反映の仕組み

`loadLanguage()` が `lang/language.json` を fetch し、`translations` に格納する。

```js
const res = await fetch('lang/language.json');
translations = await res.json();
setLang(localStorage.getItem('lang') || 'ja');
```

`setLang(lang)` は以下を行う。

1. `translations[lang]` の存在確認。
2. `localStorage.lang` に言語コードを保存。
3. `[data-i18n]` 要素のテキストを置換。
4. `[data-i18n-placeholder]` 要素の placeholder を置換。
5. `description_tail` の `[link_how_to]` を YouTube リンク HTML に置換。
6. `loadLinks(lang)` を呼び、言語別フッターリンクを更新。

## 改行と HTML

`setTextWithLineBreaks()` は翻訳文内の `<br>` を実際の `<br>` 要素に変換する。

```js
String(text).split(/<br\s*\/?>/i)
```

通常の `data-i18n` テキストは `textNode` として追加されるため、HTML は実行されない。

例外:

- `description_tail` は `innerHTML` に代入される。
- `description_tail` には固定 HTML リンクが含まれている。
- `[link_how_to]` は `js/i18n.js` 側で生成した YouTube リンク HTML に置換される。

注意:

- `description_tail` にユーザー入力や外部データを混ぜない。
- 新しい HTML を翻訳 JSON に入れる場合は、XSS リスクを確認する。

## 言語別フッターリンク

リンクファイル形式:

```text
表示名,URL
```

現在のファイル:

| ファイル | 用途 |
|---|---|
| `link/link_ja.txt` | 日本語リンク。 |
| `link/link_en.txt` | 英語リンク。 |

生成されるリンク属性:

| 属性 | 値 |
|---|---|
| `href` | リンクファイルの URL。 |
| `textContent` | リンクファイルの表示名。 |
| `className` | `lang-switcher-link` |
| `target` | `_blank` |
| `rel` | `noopener noreferrer` |

注意:

- 1 行 1 リンク。
- 空行は無視される。
- カンマ区切りのため、表示名や URL にカンマを含めない。

## 文言追加手順

1. `lang/language.json` の `ja` と `en` の両方に同じキーを追加する。
2. `index.html` に表示する場合は `data-i18n` または `data-i18n-placeholder` を付与する。
3. JS から参照する場合は、存在しないキーを参照しないようにする。
4. `JP` / `EN` 切替で表示を確認する。
5. 長い英語文言が UI からはみ出さないか確認する。

## 要確認

- `No results found.` を翻訳キーとして追加するか。
- GAS 由来のエラーメッセージを多言語化するか。
- `description_tail` に HTML を持たせる方針を継続するか。
- 英語表記の `WanderingSea` / `Wandering Sea` を統一するか。
